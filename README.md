# Attendance Management System

A C program that records student attendance and flags students whose
attendance falls below the required percentage.

## Features
- Add student records (name, roll number, classes attended, total classes)
- update student details
- Calculate attendance percentage
- Identify students with attendance shortage
- Save and load records from a file

## Concepts Used
- Control flow (loops, conditionals, menu with switch)
- Arrays
- Structures
- File handling

## How to Compile and Run
```bash
gcc attendance.c -o attendance
./attendance        # on Windows: attendance.exe
```
